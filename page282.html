This ensures they’ll remain compatible with future display technology with even more vivid colors, but makes them harder to reason about.

As you might’ve noticed, when we add 180 degrees to the hue, we sometimes wind up with values that are greater than 360 degrees, like hsl(412deg 100% 80%).

This might seem like an invalid value, but actually, we can use any real number for the hue! Even ridiculous values like 123456deg or -1337deg will work just fine.

Admittedly, it’s hard to tell with everything going on. Here’s a basic button that performs the same color transition on hover/focus:

The starting color (red) and the ending color (teal) are both quite vibrant, but it becomes dull and grey in the middle:

I would expect that the saturation and lightness would stay the same, and only the hue would shift through the animation, something like this:

Here’s the problem: when we animate background-color, the browser always does the calculations using the RGB color space, even when our colors are specified in HSL.

In RGB, we have three color channels (red/green/blue), each between 0 and 255. The browser does the math on these three channels individually. You can see why that’s a problem in this demo:

How to use: Click and drag to reposition the indicator, or focus the indicator and use the left/right arrow keys.

As we scroll from left to right, the red channel decreases as the green/blue channels increase. As a result, all three channels converge on the same value in the middle, producing a medium gray.

In other words, the browser is transitioning between these two colors using a mathematical model that doesn’t really have anything to do with how we perceive color 😅. No rational person would say that the midpoint between red and teal is grey!

I have another blog post that explains this issue in depth: “Make Beautiful Gradients”. The first half of the post explains why we wind up with this “dead zone” in-between colors.

That post is about CSS gradients, not animated color changes, but really it’s all the same thing. We can think of our color animations as a gradient that takes place across time rather than space.

There’s another issue, too. Let’s say we wanted the color to rotate by a full 360°, looping around the color wheel. Check out what happens when we try to transition between 0° and 360°:

Nothing happens. You’re not doing it wrong. Hovering or focusing the button doesn’t seem to affect the background color at all. 🤔

In order to understand what’s going on here, we have to answer a philosophical question: are hsl(0deg 100% 65%) and hsl(360deg 100% 65%) the same color?

Well, they represent something different; 0deg represents the very first color available in the spectrum, while 360deg represents a full spin around the color wheel. But ultimately, both colors resolve to the same R/G/B values.

Unfortunately, as we saw above, the browser doesn’t do color interpolations in HSL; it first converts both values to rgb() and then transitions the values for all three color channels. And since hsl(0deg 100% 65%) and hsl(360deg 100% 65%) both resolve to the exact same rgb() value, we wind up not transitioning at all.

Fortunately, I found a solution that solves these problems, and offers better performance to boot. ⚡

Now, it’s not quite the same as changing the hue component of an hsl() color. Here’s a side-by-side comparison:

I’m not exactly sure how the filter: hue-rotate() algorithm works, but it tends to produce darker color variations. I’ve found it works best if I pick slightly lighter and less-saturated colors.

And honestly, I think two full rotations (720deg) is probably a bit much. I wanted to make sure the effect was clear in this demo, but in practice, I’d probably pick a smaller value, maybe something in the 180°-540° range.

Another benefit of using CSS filters is that they tend to be more performant than the alternatives. When we change background-color, the browser has to repaint each particle on every frame. With filter, the browser can reuse previous paints and instead apply a lightweight transformation on every frame, tinting the existing pixels rather than recalculating them from scratch.

If we only have 10-20 particles, the difference is negligible, even on low-end hardware. But at a certain scale, this would become a bottleneck, and I think it’s good to give ourselves that headroom! If we ever want to crank up the number of particles, we won’t run into any problems (at least, not with the color-changing part).

When transitioning the background-color property, the maximum color shift we can do is 180 degrees. This is because the browser treats hsl(0deg 100% 50%) and hsl(360deg 100% 50%) as the same color.

I was curious if it was possible to solve this problem without using filter, and I was indeed able to come up with something, using the power of CSS custom properties. ✨

If you’ve never seen @property before, it’s a technique we can use to assign a type to our custom properties (AKA CSS variables). If we let the browser know that --hue is an , the browser can then animate this property when the value changes!

This is pretty complex stuff, so let me explain. On hover, we change the value of --hue from 0deg to 720deg. The browser will then recalculate the background color on every frame using this color, over the 2000ms specified with the transition property.

Before, the browser was only doing the HSL -> RGB math for the starting color and the ending color, which led to the limitation we saw above. With this new approach, the browser has to recalculate it on every frame, since it’s being dynamically built up using that --hue variable. As a result, we no longer have any issues!

Ultimately, this is a fun little bit of magic, but it’s not really the best solution. Our approach using filter is more performant and has slightly better browser support(opens in new tab) (although both approaches are well over 90%).

Easy School Science Club Ideas

📅 Sep 08, 2025  |  Category: Entertainment  |  Read Source →

Lots of people have been asking me for school science club ideas recently, so I’ve put together a collection of science experiments and activities that I think would work really well for Primary/Elementary school age children at a science club!

If you’re a teacher, parent or home educator looking for easy, inexpensive, inspiring and exciting school science club ideas, you’re in the right place! Scroll through my ideas, print the worksheets and get ready to turn your classroom or kitchen into the best science lab around.

Learn about animations and persistence of vision with a flipbook. My free template makes this an easy activity, and all you need is paper, pens and paper clips.

First up are our easy Scribble Bots. These are very simple to make using inexpensive and reusable materials. Children can try changing the size of the container, location of pens and alignment of the moving arm to see how the drawing pattern changes.

Build a robot that can draw an almost perfect circle.

Create a robot that can draw a dotted line.

Try using a small cleaning brush instead of a Pringles can.

Build towers and test how stable they are with different edible foundations. I’ve also got instructions for how to make a simple seismometer.

If you don’t want to use food, playdough, and clay, foundations work as well!

Investigate to find out how to make the tallest stable tower. One idea is to use stabilising toothpicks to form triangles.

Experiment to find the most stable edible foundation.

Craft stick chain reactions are great fun and easy to set up once you get the hang of them. It’s definitely worth persevering with for the final spectacular result.

Have a mini competition to find out who can build the longest chain reaction.

Experiment with longer sticks to find out if the reaction jumps higher.

Design and build a different kind of chain reaction, which is sometimes called a Rube Goldberg Machine. Rube Goldberg machines are fantastic for a science club, as children can work in teams to set up unique chain reactions!

Give children a selection of buoyant and non buoyant materials and ask them to find a way to make a small action figure float.

Investigate to find the smallest amount of material that can be used to make a figure float.

Try to get an action figure to float by another method. Adding salt to water to increase the density is one idea. Or make a boat for the figure to lie in.

Try blowing up a balloon with Alka Seltzer, an effervescent vitamin tablet or popping candy. If you have the outdoor space, this works really well, followed by a film canister rocket. The fact that the children have seen just how much gas is released by an effervescent tablet makes it easier to understand why the pressure builds up so fast inside the film canister.

Experiment to find out how to speed up the blowing up of a balloon reaction. Increasing the temperature of the water or adding more of the effervescent tablets is one way to do this.

Draw a picture on a balloon so it expands as the balloon grows.

These are a super easy, low cost activity using just paper and paper clips. Paper spinners can be used for lots of different investigations, children can try dropping them from different heights, making different sized spinners and observing how they fall differently or adding more or less weight to the bottom end.

Have a competition to see who can make the biggest paper spinner that spins at least once on its descent?

Find out the size of the smallest spinner that still spins.

Race to see who can make the slowest falling spinner.

Try catapulting different size and weight balls to see which go the furthest, or release from different angles. Children could also design a target and find a way for the ball to make a mark when it hits.

Follow my easy catapult instructions to get started.

Catapults are a fantastic science activity for a school science club. They’re low cost, easy to make and can be taken home afterwards.

Who can make their ping pong ball go the furthest?

Who can build the biggest/smallest catapult?

This is another easy activity and a great demonstration of how salt lowers the freezing point of ice.

To make ice cream with ice and salt, simply place sugar, cream and flavouring into one sealed bag, then place that big inside a bigger bag container ice and salt, roll and twist the bags together until your cream turns into lovely squishy ice cream! Experiment using milk, cream, flavoured milk and syrups to see which give the best flavour.

Remember this can get very cold for little hands so gloves or a tea towel might be a good idea.

Make a density jar and ask the children to find objects to float on each layer. Give the jar a good shake and watch as the layers separate. Use a pipette to drop water into the oil, observing how it forms spherical shapes.

Once you’re finished with the density jar you can add a bit of food colouring to the water and turn it into a lava lamp by adding an alka seltzer.

Who can make a density jar with the most layers? Try treacle, golden syrup, ice cream syrup, milk, water, honey, and washing up liquid ( dish soap ).

Viscosity Races are brilliant fun and a great way to learn how the thickness of a liquid changes how it flows.

Mark two points on a large piece of paper and time how long each liquid takes to run between the two lines.

Experiment to find the fastest and slowest moving liquids you can.

Discover what happens to the speed of the liquids when you change the gradient of the ramp.

Place skittles in water and watch as the colour dissolves from the sweets. You could try using warm, hot and cold water to investigate if changing the temperature of the water speeds up the reaction.

How about this fun twist on the traditional egg drop experiment? Ask children to place different materials into sealable plastic bags, place an egg inside and then drop from high up to see which protects the egg the best.

Try changing the material inside the bag, the surface the egg drops onto or the size of the bag to extend the task.

Who can build the most effective landing pad for an egg to drop on without breaking?

Find out who can build the tallest spaghetti and marshmallow tower. Straws and plasticine also work well for this.

Create a working water slide or marble run using cardboard tubes and foil.

A science club is a great way to explore beyond the curriculum and increase the amount of science children are exposed to in a fun environment.

A science club can provide a relaxed environment for children to experience exciting, hands-on science without the restrictions of normal classroom learning.

There’s often a stereotype around science that a science club and early exposure to science can challenge. Exposing children to different scientific fields and learning about trailblazers in the science community can help break down barriers.

Science is all about the world around us, but encouraging children to look around, ask questions, and discover how things work can help develop a curious mind, and a child who questions and searches for solutions to problems.

Science activities help children to think critically and search for answers.

Science experiments are a fantastic way to learn that things don’t always work the first time, but if you’re patient and keep trying, problems can be solved!

Easy Homemade Cranberry Sauce

📅 Sep 03, 2025  |  Category: Other  |  Read Source →

This easy cranberry sauce recipe has been a fixture on my family’s Thanksgiving table for years, served alongside my mother’s elaborate Indian-inspired holiday dishes. With just 10 minutes on the stove and a handful of ingredients—fresh or frozen cranberries, sugar, orange zest, and water—it delivers the bright, tangy flavor that cuts through all the richness of the holiday meal.

My mom started making cranberry sauce after tasting a homemade version at a friend’s house. Over time, she made it her own, dialing back the sugar for extra tang and adding orange zest for brightness. We’ve tried fancier versions with maple syrup, chiles, and warm spices, but always come back to this stripped-down sauce. Anything more dulls the sharp cranberry bite we love.

A splash of orange liqueur is entirely optional, and you can swap some or all of the white sugar for light brown sugar. Best of all, you can make the sauce up to five days ahead, leaving one less thing to think about on Thanksgiving Day.

Can I use frozen cranberries to make cranberry sauce?

Absolutely. Fresh and frozen cranberries both work, and there's no need to thaw frozen berries before cooking. They may take a little longer to burst and become jammy.

Yes. The liqueur adds another layer of citrus flavor, but it's entirely optional. Brandy-based Grand Marnier brings warm, vanilla-like notes, while Cointreau offers a cleaner, brighter orange flavor. You can also simply leave it out; the orange zest provides fruity brightness on its own.

Cranberries contain natural pectin, which helps the sauce thicken as it cools. If yours still seems thin once cooled, return it to a simmer and cook until it coats the back of a spoon and holds a line when you run your finger through it.

What can I do with leftover cranberry sauce?

Cook 1 (12-oz.) bag fresh or frozen cranberries, ¾ cup granulated sugar, 1–2 Tbsp. Grand Marnier, Cointreau, or other orange liqueur (if using), 1 Tbsp. finely grated orange zest, a pinch of kosher salt, and 1 cup water in a medium saucepan over medium heat, stirring often to prevent scorching, until cranberries burst and sauce becomes jammy and coats a spoon, about 10 minutes.Let cool before serving.

Do ahead: Cranberry sauce can be made 5 days ahead. Transfer to an airtight container; cover and refrigerate until well chilled.

Create You Own Flipbook – FREE Animation Template

Have you ever wanted to create your very own animation? One way to do this is with a simple flipbook.

An animation flip book is a series of pictures arranged in a flip book that change slightly from one page to the next. When you flip through the book, the images appear to move, creating a short animation.

It’s a fun way to bring images and drawings to life without a screen! Flipbooks work because of a phenomenon known as persistence of vision.

My simple template allows you to print off a rocket animation and includes blank pages to draw your own sequence!

Make a flipbook with my rocket images and then draw your own!

Either use my template or cut about 20 pieces of paper to the same size. They should be small enough to flip through easily.

Draw the same image on each page, but in a slightly different place.

Attach the papers in order using two paperclips.

Flip through the book and watch your drawings come to life.

When you see an object, the information is sent to your brain, where it is processed to form the image you see. When you flip through the flipbook, the brain fills in the blanks, creating an illusion of movement!

Your eye and brain can’t process a new image instantly as you flip through, so it merges them together. The more images you have and the smaller the changes are, the smoother the animation will appear.

This same principle is used in cartoons and animation on the big screen!
